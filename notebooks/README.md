# Notebooks

- `demo_walkthrough.ipynb`: the runnable, cleaned demonstration using synthetic data and the maintained risk pipeline.
- `legacy/original_exploration.ipynb`: the earlier exploratory notebook from the university project, kept for reference. Outputs and execution counts have been stripped to avoid disclosing original event records and network metadata. The original CSV has been lost; this notebook contains exploratory rules and plots; it is **not intended to run as the current pipeline**.

The main application and training code in the repository root are the maintained implementation.
